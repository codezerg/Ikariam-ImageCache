Ikariam Helper

Adding more images

  1. Play the game normally — the extension records every image the page loads.
  2. Open the popup and click Download safe list.
  3. Save it over safelist.json in the repo.
  4. Run npm run scrape to download those images into src/assets/ and regenerate the redirect rules.
  5. Run npm run build and reload the extension.

Images are bundled into the extension package, so they load from disk with no network request at all. Editing a file in src/assets/ replaces that image in the game.
